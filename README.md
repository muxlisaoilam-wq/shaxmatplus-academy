# Shaxmat Plus Academy

Bolalar uchun shaxmat darslari (8×10 taxta, Taʼminotchi figurasi). 7 til, 2D va 3D taxta, internetsiz ishlaydi, Telegram Mini App sifatida ochiladi.

**v2.0:** yangi rang-barang dizayn · «Qoidalar» bo‘limi (muallif, 8×10 taxta, barcha qoidalar) · har bir figura darsidan keyin test · barcha darslardan so‘ng o‘rtacha bot bilan o‘yin (maslahat berib turadi) · Play Market tugmasi.
